# صفحة التحويل الشخصية

## التشغيل
افتح المجلد في VS Code وشغّل `index.html` بامتداد Live Server. النسخ يعمل بأفضل شكل عبر localhost أو HTTPS.

## تعديل البيانات
كل البيانات موجودة في `config.js`، وهو مصدر البيانات الوحيد للموقع. عدّل النصوص بين علامتي التنصيص فقط، ثم انشر الموقع من جديد لكي تظهر التعديلات للزوار. ضع داخل `appLink` رابط الدفع الرسمي الذي تنسخه من التطبيق، ولا تخمّن رابطًا.

## صور QR
أنشئ مجلدًا باسم `images` وضع داخله `instapay-qr.png` و`vodafone-qr.png`.

الموقع ثابت ولا يستخدم Firebase أو أي قاعدة بيانات. لا تضع PIN أو OTP أو رقم بطاقة أو كلمة مرور داخل الموقع، لأن محتوى `config.js` متاح علنًا لأي زائر.
